# Stage27m: flat-world MOVE DEV

Stage27m is an explicit operator DEV opt-in stacked on Stage27j, with the
same original A/B owners, bounded L1 choice, target, preset, L0 loop,
physical Action issuer and WAL. It requests a new vanilla superflat World
with bedrock, dirt and grass layers, no generated structures or natural
creature spawning. Existing modes retain their prior World settings.

Before the Stage27j motor hook, the owned Paper console checks grass support
and air in a coarse eastward corridor around RelayA and checks the same
volume for other entities. The command and Paper response are evidence, not
Self perception, authenticated collision geometry, or Action causality. A
missing success response refuses physical issuance; a timeout does not
identify the failing condition. The native probe remains the source for the
5m east Target. Actual spawn, terrain, entity state and result must be
reported from the one permitted run, not inferred from configuration.

Run only after exact-HEAD CI, regression, model/process ownership and
physical IO preflight. Use `--stage27j-long-move --stage27m-flat-world`
with the original explicit EULA, DEV, jar and model options. Never retry a
World or uncertain Action. Save original evidence, stop owned processes,
verify both WALs and read back SHA256SUMS. No QUAL/SCIENCE claim.
