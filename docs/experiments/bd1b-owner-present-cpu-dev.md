# BD1b original-owner Present projection (CPU/offline)

Before the first resident login, bootstrap explicitly calls
`ResidentCognitiveWorkOwner.register_present_schema(self_id, snapshot)` for each
Self. The immutable snapshot must match that owner's current PatternRegistry
revision. The explicit v1 mapping is the D `exploratory` module to a single B
`exploration` GOAL pattern with `EXPLORE` predicate and pattern version 1;
the module must support its active mode and `QUESTION_CANDIDATE`. These are
different contracts, not interchangeable names. OFF or dependency-ineligible
configurations are rejected. No pattern or module is generated by projection.

This is in-memory run configuration, not checkpoint data. After restore, a new
resident must be explicitly bootstrapped again before its first login using a
trusted configuration matching the restored registry. Re-registration after
restore has not been demonstrated by this milestone.

`build_bd1b_owner_present` re-runs the SOURCE reconciliation under the resident
lock and projects the current retained cognition and exact native probe. It
returns the source, registered schema and transient Present; no caller-provided
Present or source revision can be submitted. The readout is not a durable
receipt, real Paper attestation, Question adoption, or action authority. It
must not be reused as proof of a later live state. The synthetic fixture does
not run a real World or model.
