# BD1b real bounded model one-shot capture (DEV, source-gated)

`experiments.bd1b_real_original_capture_dev.capture_bd1b_real_original_once`
is an **opt-in callback inside a qualified already-running original
Paper + A/B Native Owner bridge**. It does not launch Paper, create a
separate Resident, open a new Self source or run L2/Physical Action.

It refuses unverified exploration Schema activation via the
`inspect_bd1b_real_issuer` gate *before* recording any model POST or
attaching the original GPU lane. It pins the actual GGUF/PID/GPU/endpoint
and single idle slot, freezes an original owner Question turn, saves the
original cognition/WAL bytes, attaches one original inference lane,
uses `issue_original_adoption_once`, and captures the exact
`urllib` HTTP entity request and response bytes plus the accepted
model result. It refuses a second request, a foreign backend, changed
Native/Paper source, or WAL mutation. It preserves an exclusive
`issuer-HOLD.json` and quarantines the original bridge on uncertainty
after attachment. Parent owner must retire/logout both real Self
sessions and independently audit the immutable Paper/Native sources.

A successful callback returns an **UNAUDITED capture path** with
`BD1B_REAL_CAPTURED_INDEPENDENT_AUDIT_PENDING`, not a real Self issuer
attestation. It needs an independent verifier for original Native/Paper
logs, original Owner durable revisions and raw llama-server model
content, plus the World typed cut and separate-process restoration.

The existing Stage28c2b restored source **cannot use this callback**:
its current checkpoint has no independently authenticated exploration
Schema activation and `bootstrap_restored_schemas` remains HOLD.
Do not inject an exploration Schema after restore. A source-qualified
fresh original World or independently qualified persisted Schema
activation is a prerequisite for real execution.

Offline pytest mocks a local HTTP response and CPU source; no actual
Gemma, RTX 3060, Paper or World trial occurs in CI. The previous
`BD1b1A2_ADOPT_COMMIT_CPU_OFFLINE_PASS` remains separate, and
`SELF_ADOPT_ISSUER_NOT_ATTESTED`, BD1b/BD1, QUAL/SCIENCE and
crash durability remain HOLD.
