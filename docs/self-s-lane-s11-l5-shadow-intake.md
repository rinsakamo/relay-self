## S11 owner boundary

`self_s11_l5_shadow_intake.review_l5_against_s10` consumes:
1. The exact S10 `S10ShadowAB` **same current source/no Action** negative result;
2. The same typed S-provided `MineflayerObservation` probe;
3. An explicit S-origin *claimed* current-source digest/seq/session pointer;
4. L5's exact ShadowAdvice data, generated by the frozen L5 implementation.

It rejects mismatched S10 states, forged action/goals/science flags, invalid
L5 schemas or unsupported positive contrast. It compares L5 no-memory
Action reference against S10's actually selected original S49 L0 reference.
Different sessions, sequences, unadmitted claimed probe SHA or action
vocabulary classify `l5_s10_not_paired_no_action`—**not** an experimental
effect. This is particularly important because L5's published synthetic
test uses `OPTION_A/OPTION_B`, while S10's S49 fixture uses
`MOVE_AWAY`. Renaming one of them to infer causality is forbidden.

A hypothetical matched positive is at most
`shadow_difference_non_authorizing`. The advice is never routed to
`NormalWorldL0.decide`, `grant`, `NormalSessionActionExecutor`, S10
LearningUpdateAuthority or S11 Habit. Neither S11 nor a caller-supplied
digest list can authenticate actual Mineflayer original bridge bytes, goal
evidence or genuine heldout outcome.
