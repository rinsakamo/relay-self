## Ownership and limitations

- Cognition **ADMITTED** is not Action AUTHORIZED. Cognition grant, proposal grant and issue grant are **three separate caller-supplied authorities**.
- The S39 gate is **caller-serial, in-memory and opt-in**; its Python public attributes and the existing ActionSupervisor are **not an unforgeable capability-security perimeter**. Only calls routed through the tested gate receive this bounded protection. It does not globally prevent other code from calling the old Action API.
- The S39 one-shot dispatch is consumed **before** external IO; no automatic retry or idempotent distributed dispatch.
- A Node loss after ISSUE or in the course of physical dispatch is **not qualified**; uncertain real Action outcome and crash recovery are S40 candidates.
- World threat is experimenter controlled. The Current Intent, threshold, fixed planning rules, release decisions and proposal/issue grants remain externally configured; this is not autonomous goal discovery or free-running agent behavior.
- The retained risk weight 4/rev1 is imported from frozen S19 **synthetic but governed** learning history. There is **no S39 real Minecraft learning update**.
- No persistent global replay ledger, signed World identity, cryptographic grant, distributed exactly-once guarantee, Python host crash survival, lossless message transport, or unattended reconnect is claimed.
