## 1. Critical correction to the Bug-0 plan

**EAT and ATTACK are already supported by existing Mineflayer primitives and the controlled experiment in main.** They are **not new commands to invent**. The current S49 *product* route remains a separate MOVE-focused serial-Action integration; reusing a command requires S-owner review and authority/custody/source admission, not a copy-paste second executor.

**REST is not necessarily a new primitive Action.** P1 #626 already implements virtual physical-fatigue recovery on **physically verified full World-tick WAIT**; the M lane models basal consumption during WAIT. Bug-0 REST should begin as a maintenance Goal/Intent selecting admissible inactivity when safe, then reading qualified fatigue/body evidence, not an automatic energy/HP increment or a REST-labelled native command.

**WB already contains SelfWorld and SelfBody typed views**; S-side bounded cognition slices and L-side governed experience mechanisms already exist. Do not create duplicate stores, three new agents, a second physical issuer, a generic action router or an unconditional new Skill registry.
