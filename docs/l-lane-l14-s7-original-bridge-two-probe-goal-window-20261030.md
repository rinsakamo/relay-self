4. Original native received stream begins with the real Mineflayer adapter-started `seq=0`, then contiguous `seq=1..N` in the same session; L14 re-parses every entire line through existing `MineflayerStreamDecoder`. The existing typed pre-Action probe bytes must be an **exact member** at its original sequence. Original `effect_result` for that exact Action must be `applied` within the separately S16-attested before/after sequence window. Every `effect_result` in the whole captured inbound stream and every original outbound `effect` send-attempt must name **the same Action ID**. Unknown outbound command types, multiple Action IDs, duplicate JSON keys, altered source seq, missing/invalid `effect_result` all fail closed.
5. At exactly `goal_observed_seq` and `goal_observed_seq + 1`, **two sequential actual native probe observations** must follow the S16 closure (no non-observation received messages in this post-terminal gap). Using original observed horizontal x/z, L14 independently computes both distances to external target and compares their goal tolerance class and positional stability. Two stable inside probes: `REACHED`; two stable outside probes: `NOT_REACHED`; mixed/unstable: `UNDETERMINED`. Externally claimed positive/negative result must agree; `UNDETERMINED` is *not* a negative reward.

This is a stronger **source and geometry consistency check**, not a private signing function. Existing sent original lines are recorded *before* write/drain and contain no timestamp or native seq; their order cannot prove exactly when the server processed an Action. Even with a full captured single-Action stream, unobserved server commands, other actors and environmental changes are not excluded; no actual intervention absence or causal motor effect is established. The separate S/R/V owners must check a trusted external original and physical protocol if qualification is sought.
