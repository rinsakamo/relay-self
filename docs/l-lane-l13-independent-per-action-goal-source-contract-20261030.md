3. **Separate independent Goal-owner receipt**: prospective `L13_EXTERNAL_PER_ACTION_GOAL_V1` JSONL containing exact session/Action IDs, matching pre and S16 exact SHA256, exact S16 `action_end_seq`, strictly later `goal_observed_seq`, explicit external `criterion_id`, separate owner and asserted no intervening Action. Goal status must be one of `REACHED`, `NOT_REACHED`, `UNDETERMINED`. A physical `NOT_REACHED` is **not** derived from S16 executed / Goal distance or the eventual final World report; it must come from the independent criterion and actual external owner.
4. **Distinct S/R/V admissions and checks**: `L13IndependentSourceAdmission` requires three different source owners, a fourth independent review provenance and separately admitted exact SHA256 byte hashes for pre-Action Present, original S16 terminal and original Goal. L13 refuses duplicate JSON fields, wrong/missing SHA or schema fields, cross-Action/session/revision, reordered source sequences, missing no-intervening Action attestation, altered goal result or owner, and future/current epoch evidence. A typed admission is an external **claim**, not digital signature verification or physical authenticity; L13 does not claim it independently authenticated a real World. Actual S/R/V verification must inspect original owner bytes and runtime identity.
5. **Existing ownership**: only for `REACHED`/`NOT_REACHED`, the gate builds a *read-only source-shaped candidate* with existing `qualify_episode` L1/S16, L3 `ExternalGoalLabel` and `GoalSourceAdmission`, and L10 `PriorWorldBodyEpisode`.
