# S44 bounded feature slice

ReactiveL0 is a bounded, session-local native-event consumer which can generate source-checked WAIT or an independently granted MOVE_AWAY action **request**. It does not issue a command or establish a physical result itself. Existing Action/World owners must handle that downstream. It never calls a language model; no automatic recovery, persistent daemon or Minecraft production qualification is claimed.
